## 一、代码声明的兼容范围（编译期约束，非实测承诺）

`services/agent-android/app/build.gradle.kts`：
- `minSdk = 26`（Android 8.0）
- `targetSdk = 34` / `compileSdk = 34`（Android 14）

即代码层面"允许安装"到 Android 8.0 及以上，但这只是编译约束，**不代表任何一个版本被真机验证过**。全仓库搜索，安卓端核心采集/无障碍逻辑里只有 1 处显式判断了系统版本（`DeviceAccountScanService.kt` 判断 `Build.VERSION_CODES.R`，即 Android 11），其余全部假设各版本行为一致。

## 三、观测到的模式

- **覆盖的 Android 版本**：8.1（2 台）、13（1台）、14（1台）、15（1台）——跨度从 2017 年系统到最新系统
- **覆盖的品牌**：荣耀 ×2、华为 ×2、小米/红米 ×1——华为的后台进程清理策略在业内以激进著称，是否需要额外的保活/权限引导，目前代码里没有针对性处理
- **同一根因（WS 401）在不同 Android 版本上表现出不同的用户可见症状**（掉线 / 找不到设备 / 一直未注册）——说明"症状不同"不能作为"根因不同"的证据，容易误判成多个独立 bug（这次差点就分别排查了）
