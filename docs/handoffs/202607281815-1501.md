- 真机验证过程：
  1. xian-rog 缺 .NET SDK（只有 runtime）→ 从本沙箱下载 SDK 安装包，经 COS 中转（直连中国大陆慢/超时，符合 CLAUDE.md「国内机器下载失败→device-transfer skill」规则）安装

  3. 通过 SSH 直接 exec 启动 exe 会在非交互 Session 0 崩溃（`WebView2` `CreateCoreWebView2ControllerAsync` 报 `COMException 0x80070578` 无效窗口句柄）——找到 CI 自己已用过的 `PsExec64.exe`/`schtasks /IT` 手法，改用 Windows 任务计划程序以 `/IT`（交互式登录）方式把 exe 真正跑进 Session 1 桌面
