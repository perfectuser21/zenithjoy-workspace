# SDK33搜索占位文字不能直接当成残留

小彩和小白本轮清空搜索框后，原生树将动态搜索提示放进text且省略hint。只允许空text或hint相等会误拒；仅允许任意非nonce文字又可能漏真实残留。

沿用既有SDK31证明：empty仅是候选，对唯一聚焦的原生输入框先MOVE_END清除选区，粘贴必须只追加并精确得到完整本轮随机nonce，才证明此前实际为空。任何真实残留、部分/旧剪贴板与错框均拒绝。SDK31输入和copy实现保持原样。
