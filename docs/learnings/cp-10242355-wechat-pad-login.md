## 微信原生二维码入口复用（2026-10-25）

### 根本原因

原生入口可能被登录状态和菜单隐藏，临时命令缺少统一的版本、Pad配置、设备归属及锁清理验收。磁盘配置和二维码页面也不能证明实际设备类型或认证成功。

### 下次预防

- [x] 将导航限制为唯一固定原生组件，每次核验环境；已有二维码或已登录页面不重复请求。
- [x] 对双租约及公共锁的模糊获取、释放失败分别读回，未知清理不得报成功。
- [x] 使用成对CRC及typed MMKV解析，显式报告运行时设备类型未观测与用户确认要求。
- [x] 永久CI覆盖未知前台、版本漂移、错误配置、过期二维码、锁冲突和本地help/status不触机。
