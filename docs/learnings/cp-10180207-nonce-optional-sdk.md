# 可选元数据须按真实执行输入回放

官方生成registry的sdk列是可选的。把原XML放进强制SDK33的harness，会漏掉真实空SDK输入绕过证明的错误。测试必须连同原registry及生产解析器回放，并覆盖显式空和unset，不能用运行时名称推定硬件版本。

本次仅为缺省SDK启用已经建立的唯一原生字段和nonce追加证明；不填写虚构SDK、不改真实硬件台账。相同的残留和旧剪贴板负例在缺省配置下仍须拒绝。已声明31的输入复制保持原字节。

原生评论资源ID会整体变更。新布局须用本轮原profile/returned先复现，再以完整ID组合和同一唯一面板锚点兼容；逐个任意通配会混合不相干控件。蓝机eyi/flq/jn1/ki8原件先红后绿且旧两布局回归通过，只证明解析能力，不可据此冒认该轮所有时效守卫或真实采集均已通过。
