## 本次要做的
现在Dashboard的"智能获客"主页和其下属页面是历史遗留的大杂烩，跟真实的Golden Path完全对不上：Hub页4张卡是并列模块而不是先后顺序；"客户分析"和"触达中心"两张卡都硬编码指向同一个错误URL且都撒谎标"即将上线"（触达逻辑其实已经在跑）；acquisition-config页混了4样不相关的东西（Path1无关的主号状态、跟专门采集页重复的关键词入口、没实现的开场白话术、真实的参数配置）；Leads页做得对但是孤儿路由进不去；账号管理页的"抖音昵称"列显示错误数据。本次重做IA，让4个页面的入口和内容真正对应客户完成获客这件事的先后顺序。

## Golden Path
1. 管理员打开"智能获客"主页 → 看到4张按Golden Path顺序排列的卡片：①绑抖音小号 ②采集 ③看线索 ④触达记录，不再是4张互不相干的并列模块
2. 管理员点"绑抖音小号" → 进账号管理页 → 表格只显示"小号名"列，不再有显示错误数据（如"抖音创作者中心"这种页面标题）的"抖音昵称"列
3. 管理员点"采集" → 进采集任务页（这个页面本来就是对的，不改）
4. 管理员点"看线索" → 直接进Leads页（不再需要记URL手动输）→ 能看到评论内容/最新回复/负责人/评级
5. 管理员点"触达记录" → 看到真实的触达历史列表（谁、什么时候、发没发成功，读dm_assignments/dm_outreach_log真实数据）→ 不再是骗人的"即将上线"标签
6. 管理员想改采集频率/触达频控这些参数 → 从一个独立的"设置"入口进（原acquisition-config页瘦身后只剩这部分真实功能），不再冒充"客户分析"或"触达中心"
7. 失败路径：触达记录里如果这个租户还没有任何真实触达数据 → 显示"暂无触达记录"空状态提示，不报错
