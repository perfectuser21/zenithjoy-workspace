# 小改动 PrepPRD：工作机排期改回 table —— 按部门分组，容器固定高度内部滚动

## 改什么

工作机页右侧从纵向日历（`DayCalendar`）换成 `DeptTaskTable`：

1. **table 形态**。每件活一行，四列：时间 / 任务 / 状态 / 说明。
2. **按部门分组**。每个部门一个分组表头（部门名 + 该组件数 + 已完成数），部门顺序照约定的部门清单（智能获客 / 新媒体部 / 私域客服 / 视频剪辑），不是字母序也不是随机序。
3. **组内从早到晚**，按开始时刻升序。
4. **容器高度钉死、内部自己滚**。列头 sticky 在顶部，滚下去仍知道哪列是哪列。页面总高不随任务数增长。
5. 并行标记保留：时间区间重叠的活带「并行 N」，说明列写出同时在跑谁。并行判定跨部门有效。
6. 跨天的活在时间列写出「次日 HH:MM」。

一屏一台（顶部芯片切机）、左边实时画面、日期前后翻、部门筛选全部保留。`DayCalendar.tsx` 下线。

## 为什么改

主理人原话：「我觉得一个 table 的形式会比较好，就直接都是那种 table。比如说我从早到晚怎么排序，每一个事情你分组一下，比如每个部门从早到晚是怎么排的，以 table 的形式去分。我一直在说，我们这一页的 table 你不要特别长让我去滑，页面的高度是定的就这一页，然后你在里面可以加一个上下滑杆。」

日历用色块表达时间，块的长度好看但字少；主理人要的是能逐行读的清单。固定高度这条他已经说过三次，这次把它焊进 smoke 守卫。
