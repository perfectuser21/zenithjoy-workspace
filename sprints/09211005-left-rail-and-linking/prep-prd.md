# 小改动 PrepPRD：左栏改小窗配数字，条表双向联动

## 改什么

### 1. 新增 `DeviceRail`：画面是配角，数字是主角

左列不再被 600px 高的画面占满：

- 栏顶一行：设备名 + 序列号 + 在线/离线 + 「步骤流 →」
- 画面缩成小窗（宽 150，按 9:19.5 约 325 高），点击放大成弹层；遮罩点击与 Esc 都能关；换设备自动关闭
- 画面下方列出这台机今天的关键数字：已完成 / 失败 / 待跑 / 各部门额度 / 正在跑第几步（空闲就写空闲）

### 2. 顶部三行压成两行

原来是「标题+日期」「设备芯片」「部门筛选+图例」「设备名+序列号+步骤流」四段。设备名移进左栏后，芯片与部门筛选并进同一排（`data-testid="filter-bar"`），省出一行的纵向空间给表格。

### 3. 说明列自适应

去掉 `w-[30%]`，没内容时把宽度还给任务名。

### 4. 条子与表格双向联动

- 鼠标划过条子某一段 → 表格里落在那个时段的行高亮（`data-hot="1"`）
- 鼠标划过表格某一行 → 条子上对应位置高亮
- 两侧各出一个 `onHoverAt`（报出时刻）与一个 `highlightAt`（接收时刻），由页面串起来

### 5. 条子上分明暗

占用块也算 `past`：已经跑完的压暗，还没跑的保持实色。以前整条绿得一样，看不出进度到哪。

## 为什么改

主理人：「就是手机框你改了，我也没觉得改得很好看。右边的这个状态栏你改成什么样子了？……整体还有没有什么可以优化的你觉得？」

上一轮只调了边框和配色，没动体量与结构，所以他没感觉。形态三选一里他选了「缩小成小窗，下面补数据」，四条整体优化选了全做。
