# 小改动 PrepPRD：工作机页视觉打磨 —— 手机壳去拟物，整体配色与间距统一

## 改什么

1. **PhoneFrame 去拟物**。删掉钛色金属渐变边（5px）、内黑边（7px）、四个侧键、厚重投影。改成单层深色细边（5px neutral-900）+ 大圆角（30/25）+ 柔和阴影。宽度 360 → 300。状态栏遮盖与 Home 条保留，这两条是功能不是装饰。
2. **表格收一档**。状态标签改成 50 底 + 细环的胶囊；部门分段头从饱和色块改成浅灰底 + 部门色小圆点；列头改小号大写灰；边框统一 `neutral-100`；行高 py-2 → py-2.5；说明列 38% → 30%。
3. **已完成不再划删除线**，改成压暗。一屏二十多行里划掉一大片，读起来像全都作废了。
4. **占用条收一档**。底色 white → neutral-50，边框改细环，占用块 opacity-85，空白块蓝改 sky，条宽 124 → 132（免得「能插 26 单」挤）。
5. **页面**。卡片阴影改双层柔和阴影，内边距 20 → 24；芯片选中态深色无环、未选态浅灰底；部门筛选改 sky；样例数据标签改圆角胶囊。

## 为什么改

主理人：「好很多，但是不是那么好看，你知道吧？你不觉得吗？就是这个效果是我想要的效果，但不是那么好看。你能不能整体再调整一下？然后左边的那个手机也不好看。你看怎么样优化就感觉硬加了个壳上去了，也不是很好看。」

手机那套拟物壳（金属渐变 + 侧键 + 大投影）自成一体，在浅色卡片界面里像贴了张贴纸。表格那边则是饱和色块、粗边框、满屏删除线堆在一起。
