屏 3 / 4 · 判定点向导

J1–J10 判定点表

⚠️ = 法律/不可逆级误判后果，优先审阅
J2版权/水印判不出默认拦人工复核⚠️
候选方法AI自动放行/拦截 · AI主判+低置信度转人工(REC) · 上传时全量人工
所选AI 主判 + 低置信度默认转人工复核（前置闸，区别于 S4 末端 Gate）
误判后果漏判→侵权素材混入成片对外发布，法律/平台处罚风险；错杀→人工复核队列积压
J7下载前内容安全+水印自查 Gate⚠️
候选方法全靠平台事后审核 · 第三方内容安全API主动预检(REC) · 纯规则关键词过滤
所选接入第三方内容安全 API 主动预检，不确定默认拦截转人工（fail-closed）
误判后果漏判→违规内容对外发布，封号/法律责任（触发事故 SOP）；错杀→复核队列拖慢交付
J8声音克隆客户明确授权确认⚠️
候选方法默认允许事后打免责水印 · 逐次勾选授权后开启(REC) · 声纹相似度自动检测
所选客户逐次勾选授权后才开启该次生成（Gate 1，首版默认关闭）
误判后果误判"已授权"→对外发布使用他人声音，法律追责且不可逆
J1语义级去重（S1，材料级）
所选embedding 向量相似度（文件哈希对转码失效，感知哈希识别力不足）
误判后果漏判→同素材重复出现在多候选；错杀→有效素材永远进不了候选库
J3追加素材索引更新方式（S1）
所选增量索引（全量重建成本不可持续，定时批处理延迟高）
误判后果增量出错→新素材"隐身"，客户以为已加入实际永不出现，无报错
J4槶位缺素材处置（S2）
所选优先 AI 生成补拍，补拍失败/成本超限则跳过该候选（不顶替，避免叙事错乱）
误判后果错误顶替→候选叙事混乱；补拍质量判不好→AI 痕迹/穿帮混入
J5候选量控制阈值（S3）
所选语义匹配分排序 + 动态截断到 [50,300]（暴力枚举会组合爆炸，固定硬截断不考虑规模差异）
误判后果截断有偏差→客户总刷不到某类排列，隐藏的候选多样性缺陷
J6候选初筛的内容安全维度（S3）
所选候选生成阶段轻量初筛 + S4 末端仍保留完整终审（双闸）
误判后果初筛漏判→客户选中后才在 S4 拦下，体验受损；初筛错杀→候选多样性减少
J9剪映路径失效降级（S4）
所选自动降级 FFmpeg 直出 + 显式提示（剪映精修非刚需，交付优先于精修）
误判后果不显式提示→客户误判"功能不稳定"而非"走的是标准渠道"
J10候选级去重（S3，区别于 J1 材料级）
所选候选组合签名（素材ID集合+排列顺序）相似度/Jaccard 阈值比较
误判后果漏判→大量近似候选，多样性缺陷被隐藏；错杀→挤占 [50,300] 候选名额
